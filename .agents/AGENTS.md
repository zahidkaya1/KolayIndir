# Kolayİndir - Proje Geliştirme Kuralları

1. Bu proje Unity kullanmıyor; Unity MCP araçlarını çağırma.
2. Değişiklik yapmadan önce mevcut klasör ve Git durumunu incele.
3. Büyük değişiklikleri küçük ve test edilebilir adımlara böl.
4. Her değişiklikten sonra ilgili test veya build komutunu çalıştır.
5. Kullanıcının onayı olmadan git commit veya push yapma.
6. Tüm Git commit mesajlarını Türkçe yaz.
7. Geçici ve gizli dosyaları repository içine ekleme.
8. Mevcut public API ve proje mimarisini gereksiz yere bozma.
9. Görev sonunda değişen dosyaları ve test sonuçlarını raporla.
