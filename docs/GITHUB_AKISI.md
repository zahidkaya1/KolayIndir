# GitHub Çalışma Akışı

## İlk akşam yapılacaklar

1. GitHub üzerinde `kolay-indir` adında boş depo oluştur.
2. ZIP içindeki proje klasörünü bilgisayara çıkar.
3. Klasörü Antigravity ile aç.
4. Terminalde `scripts\kurulum.bat` çalıştır.
5. `scripts\calistir.bat` ile arayüzü aç.
6. Tek bir herkese açık video bağlantısıyla test et.
7. Hata yoksa ilk commit ve push işlemini yap.

## Önerilen ilk commit

```text
Masaüstü indirme uygulaması iskeleti oluşturuldu
```

## Sonraki commit örnekleri

```text
YouTube oynatma listesi indirme hatası giderildi
Instagram bağlantı doğrulaması iyileştirildi
İndirme kuyruğu eklendi
Karanlık tema eklendi
Windows kurulum dosyası hazırlandı
Güncelleme kontrolü GitHub Releases ile bağlandı
```

Başlangıçta yalnızca `main` dalı yeterlidir. Proje büyüyünce özellik ve hata
dalları eklenebilir.
